壊れたGitリポジトリを手で直す問題集

ブラウザの中で Linux と本物の git が動きます。壊れたリポジトリを直すと、自動でゴール判定されます。

問題

    使い方

    あなたは先輩エンジニアです。後輩から「Git が壊れました」と相談が来るので、預かったリポジトリを調べて直してください。全部で10問あります。

    1. 1
      問題を選ぶ

      上の番号をクリックすると、壊れたリポジトリが用意されます。途中の番号からでも始められます。

    2. 2
      状況を読む

      後輩からのチャットと状況設定を読み、「最初に試すコマンド」で同じエラーを出してみます。

    3. 3
      ターミナルで調べて直す

      下のターミナルで本物の git が動きます。.git の中を調べ、原因を見つけて直します。

    4. 4
      直るとゴール

      リポジトリが直ると自動で判定され、解説が表示されます。

    • 行き詰まったら、問題文の下のヒントを順に開きます。最後のヒントは解答例です。
    • どのコマンドで調べればよいか迷ったら、.git エクスプローラーを開くと、.git の中をクリックでたどれます。
    • quiz check で、まだ直っていない理由を表示できます。やり直すときは、同じ番号をもう一度クリックします。
