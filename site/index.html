壊れたGitリポジトリを手で直す問題集

ブラウザの中で Linux と本物の git が動きます。壊れたリポジトリを直すと、自動でゴール判定されます。

問題

    問題を選んでください

    # dev-help

      上の番号から問題を選ぶと、壊れたリポジトリがターミナルに用意されます。

      最初に試すコマンド：
      bash
      読み込んでいます…

      quiz check で未クリアの理由を表示できます。やり直すときは、上の番号をもう一度クリックします。エディタは nano が使えます。

      .git エクスプローラー

      ファイル名やハッシュ値をクリックすると、.git の中をたどれます。コマンドを実行するたびに更新されます。
