壊れたGitリポジトリを手で直す問題集

ブラウザの中で Linux と本物の git が動きます。壊れたリポジトリを直すと、自動でゴール判定されます。

問題

    問題を選んでください

    # dev-help

      左の一覧から問題を選ぶと、壊れたリポジトリがターミナルに用意されます。ターミナルに quiz 1 と入力しても始められます。

      最初に試すコマンド：
      読み込んでいます…

      quiz check で未クリアの理由を表示、quiz <番号> で問題をやり直せます。エディタは nano が使えます。

      リポジトリの中身

      ファイル名やハッシュ値をクリックすると、.git の中をたどれます。コマンドを実行するたびに、最新の状態に更新されます。
